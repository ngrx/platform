# V22 Update Guide

## Angular CLI update

NgRx supports using the Angular CLI `ng update` command to update your dependencies. Migration schematics are run to make the upgrade smoother. These schematics will fix some of the breaking changes.

To update your packages to the latest released version, run the command below.

```sh
ng update @ngrx/store@22
```

## Dependencies

Version 22 has the minimum version requirements:

- Angular version 22
- Angular CLI version 22
- TypeScript version 6.0.x
- Node.js version ^22.22.3 || ^24.15.0 || >=26.0.0
- RxJS version ^6.5.x || ^7.5.0

## Breaking changes

### @ngrx/eslint-plugin

### `@ngrx/eslint-plugin/v9` import path removed

The `v9` subpath export that was introduced as a compatibity shim in v9 has been removed.
All imports must now use the root `@ngrx/eslint-plugin` path.

The migration schematic (`ng update @ngrx/store@22`) will update this automatically.

BEFORE:

```js
// eslint.config.mjs
import ngrx from '@ngrx/eslint-plugin/v9';

export default [...ngrx.configs.all];
```

```js
// eslint.config.cjs
const ngrx = require('@ngrx/eslint-plugin/v9');

module.exports = [...ngrx.configs.store];
```

AFTER:

```js
// eslint.config.mjs
import ngrx from '@ngrx/eslint-plugin';

export default [...ngrx.configs.all];
```

```js
// eslint.config.cjs
const ngrx = require('@ngrx/eslint-plugin');

module.exports = [...ngrx.configs.store];
```
